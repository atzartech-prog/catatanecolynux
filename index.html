Protokol Akses Remote & Persiapan Awal

Bagaimana Antigravity dan workstation Anda dapat berkomunikasi dengan gadget target tanpa monitor atau keyboard eksternal (Headless Mode).

No Root / Root

1. SSH via Termux (Android)

Metode tercepat untuk smartphone Android bekas tanpa perlu flashing ROM baru.

Perintah Setup Awal Termux: 
pkg update -y && pkg install -y openssh
# Buat password untuk user Termux
passwd
# Jalankan SSH Daemon di port 8022
sshd
# Cek alamat IP lokal
ip addr show | grep -E "inet 192\.|10\."
# Dapatkan username Termux Anda
whoami
💡 Kunci Akses: Port default Termux adalah 8022. Login via workstation: ssh user@<ip-hp> -p 8022.
Standar Linux

2. OpenSSH Server (STB & Laptop)

Untuk STB yang sudah dibooting Armbian atau Laptop lama dengan Debian/Ubuntu/Alpine.

Setup OpenSSH & Akses SSH Key: 
sudo apt update && sudo apt install -y openssh-server ufw
sudo systemctl enable --now ssh
# Konfigurasi firewall lokal
sudo ufw allow 22/tcp
sudo ufw enable
# Tambahkan SSH Key dari workstation Anda (opsional tapi aman)
# Di workstation: ssh-copy-id root@<ip-gadget>
💡 Antigravity Friendly: Menggunakan SSH Key tanpa password memudahkan Antigravity mengeksekusi otomatisasi tanpa terhenti di prompt password.
Android Debug Bridge

3. ADB Wireless (Tanpa Kabel)

Berguna jika layar HP pecah/touchscreen mati, Anda bisa mengontrolnya langsung dari shell adb.

Koneksi ADB TCP/IP: 
# Aktifkan USB Debugging di HP sekali dengan kabel
adb tcpip 5555
# Cabut kabel, sambungkan via Wi-Fi lokal
adb connect <ip-hp>:5555
# Masuk ke shell internal Android
adb shell
# Atau forward port Termux ke laptop
adb forward tcp:8022 tcp:8022
💡 Layar Rusak? Anda bisa install APK Termux via ADB: adb install termux.apk lalu kirim intent untuk auto-start SSH.
Hardware Recovery

4. Serial TTL UART (Unbrick STB)

Jalur darurat untuk TV Box/STB jika bootloader macet atau tidak dapat IP dari router.

Koneksi Serial USB-TTL: 
# Hubungkan pin TX, RX, GND dongle USB-TTL ke pin board STB
# Di Linux/Termux workstation:
pkg install minicom # atau screen / picocom
picocom -b 115200 /dev/ttyUSB0
# Tekan Enter saat menyalakan STB untuk masuk U-Boot prompt
💡 Baudrate Umum: Board Amlogic B860H/HG680P biasanya menggunakan baudrate 115200.

Tips, Trik & Menjaga Gadget Tetap Hidup 24/7

Trik praktis merawat gadget daur ulang agar tidak cepat panas, baterai tidak kembung, dan koneksi remote tetap lancar.

🔋

Solusi Baterai Kembung (Bypass Battery)

Smartphone yang dicolok 24 jam rentan membuat baterai kembung. Trik solusinya:

  • Gunakan Smart Plug timer (nyala 2 jam, mati 2 jam).
  • Gunakan aplikasi baterai charge limiter seperti AccA jika di-root (batasi di 60%).
  • Lepas baterai dan pasang modul DC-DC Stepdown (Buck Converter) 4.2V langsung ke konektor pin baterai.
💤

Cegah Android Doze & CPU Sleep

OS Android suka mematikan proses background penghemat baterai:

# Di Termux aktifkan wake-lock:
termux-wake-lock
# Matikan Battery Optimization di Settings Android -> Apps -> Termux -> Battery -> Unrestricted!
❄️

Manajemen Panas & Pendingin Pasif

Gadget tanpa kipas bisa mengalami thermal throttling:

  • Buka casing belakang / penutup plastik smartphone & TV box.
  • Tempelkan heatsink aluminium mini pada SoC menggunakan thermal pad.
  • Letakkan di dekat ventilasi atau tambahkan kipas USB 5V silent (80mm).
🔗

Akses Dari Luar Rumah (Tanpa IP Publik)

Agar server recycle Anda bisa diakses dari mana saja tanpa langganan IP publik mahal:

  • Tailscale: Mesh VPN tercepat, cukup install di gadget dan HP luar.
  • Cloudflare Tunnel (cloudflared): Ekspos web port langsung ke domain gratis dengan proteksi DDoS.
  • ZeroTier: Alternatif VPN virtual LAN aman.
